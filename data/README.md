# Data

Raw and processed datasets are **git-ignored** (large). Download the raw files into
`data/raw/` before running the pipeline; harmonized outputs land in `data/processed/`.

## UNSW-NB15 (source — 2015)

Use the **pre-partitioned** CSVs (cleaner than the four raw CSVs; include `label` + `attack_cat`):

| File | Rows |
| --- | --- |
| `UNSW_NB15_training-set.csv` | 175,341 |
| `UNSW_NB15_testing-set.csv`  | 82,332 |

Dataset page: <https://research.unsw.edu.au/projects/unsw-nb15-dataset>

Cite: Moustafa & Slay, "UNSW-NB15: A Comprehensive Data Set for Network Intrusion Detection
Systems," MilCIS, IEEE, 2015 (and the 2016 evaluation paper) — see the proposal references.

## TON_IoT Network (target — ~2019–2020)

Use the Network flow dataset (has `label` + `type`):

| File | Notes |
| --- | --- |
| `Train_Test_Network.csv` | Zeek/Bro-derived flow features; committed modern comparison set |

Dataset page: <https://research.unsw.edu.au/projects/toniot-datasets>

Cite: Alsaedi et al., "TON_IoT Telemetry Dataset," *IEEE Access*, vol. 8, 2020.
